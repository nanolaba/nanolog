## ${en:'Build and test', ru:'Сборка и тесты'}

```shell
mvn verify -Dgpg.skip=true -Dcheck=true
```

- ${en:'The `test` phase runs JUnit and then pitest with a 100% mutation threshold: every change to the code of the library needs tests that kill its mutants. A mutant that no test can kill means the code can be simpler.', ru:'Фаза `test` запускает JUnit, а затем pitest с порогом 100% убитых мутантов: любое изменение кода библиотеки требует тестов, которые убивают его мутанты. Мутант, которого не убить никаким тестом, значит, что код можно упростить.'}
- ${en:'For a quick loop, run the tests without pitest:', ru:'Для быстрого цикла запускайте тесты без pitest:'} `mvn test-compile surefire:test -Dtest=SomeTest`.
- ${en:'The library targets Java', ru:'Библиотека собирается под Java'} ${pom.properties.maven.compiler.release}; ${en:'do not use newer APIs. CI builds on JDK 8, 11, 17 and 21; Javadoc is built on JDK 8 too, which rejects what newer JDKs accept.', ru:'не используйте более новые API. CI собирает проект на JDK 8, 11, 17 и 21; Javadoc тоже собирается на JDK 8, который отвергает то, что принимают более новые JDK.'}
- ${en:'CI also runs the tests against SLF4J 1.7 (`-P slf4j-1.7`), compiles Kotlin callers (`-P kotlin`, JDK 17) and builds a jlink image with the jar (`sh src/it/jlink/run.sh`, JDK 11+).', ru:'Ещё CI прогоняет тесты с SLF4J 1.7 (`-P slf4j-1.7`), компилирует вызовы из Kotlin (`-P kotlin`, JDK 17) и собирает образ jlink с jar (`sh src/it/jlink/run.sh`, JDK 11+).'}
